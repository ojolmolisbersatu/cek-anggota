# Cek Keanggotaan OMB

Website pencarian dan pengecekan data anggota **Organisasi Motor Listrik Semarang (OMB)**.

## Fitur

- Pencarian berdasarkan ID anggota
- Pencarian berdasarkan nomor ID
- Pencarian berdasarkan nama panggilan
- Pencarian berdasarkan nama lengkap
- Menampilkan foto anggota
- Menampilkan domisili
- Menampilkan status anggota
- Menampilkan data motor
- Menampilkan aplikasi ojol
- Responsive untuk HP dan desktop

## Teknologi

Website ini menggunakan:

- HTML
- CSS
- JavaScript
- Google Apps Script
- Google Spreadsheet sebagai database
- GitHub Pages untuk hosting website
